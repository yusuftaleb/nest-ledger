Nest Ledger

A household's money, in seconds a day.

This is the Notion-style version of Nest Ledger: one household, one shared budget, in the household's own currency. It should feel like a tidy shared notebook. White pages and warm greys, rectangular buttons, colour-coded tags, and one purple button for the main action.

Principles

  • Purple means "do this". The solid purple button (accent) appears once per screen: Save, Scan receipt. Everything else is outlined, dark or plain.
  • Tags carry meaning. Status is a soft tinted tag with deep text: mint good for matched or income, peach warn for needs review, rose over for over budget. Ordinary spending is plain ink.
  • Flat and bordered. Cards are white with a 1px line and 12px corners. No shadows.
  • Colour blocks for emphasis. Each screen may use at most one navy band (the monthly summary) and one highlight yellow card (the weekly check-in).
  • Seconds to add. Scan, check, save.

Voice

Plain and friendly. Short sentences, sentence case, no exclamation marks, no emoji.

DoDon't
"$188 left in Groceries""Great job! You're crushing it"
"Couldn't read this receipt. Try a flatter photo.""Error 422: extraction failed"
"Matched to bank statement""Reconciliation status: true"

Money formatting

  • Format: en-CA, CAD, always two decimals: $1,234.56.
  • Spending: true minus sign (U+2212), ink: −$14.50.
  • Income: plus sign, good green: +$1,140.00.
  • Always tabular-nums.

Type

Inter stands in for Notion Sans, the Inter-based face Notion uses, which isn't publicly available. Use 600 for headings, 500 for buttons, tabs and amounts, 400 for body. Body text is 16px with 1.55 line height. Headings are tracked slightly tight.

Shape

  • Buttons and inputs: radius-md (8px) rectangles, never pills.
  • Cards: radius-lg (12px).
  • Tags and badges: radius-sm (6px).
  • Pills only for the category filter tabs.

Layout

  • Phone first: one column, a space-4 gutter, sections space-6 apart.
  • Bottom tab bar with a purple Add button.
  • Period switching (Month, Quarter, Year) uses a segmented control: a warm grey track with the active option raised in white.
  • On a laptop the content caps at 720px.

Icons

Lucide icons (lucide-react), 20px with a 1.75 stroke, ink-muted at rest and ink when active. Each category has one icon, shown in ink on a soft tint of its colour.

Components

Button (primary, secondary, dark, ghost), Amount, CategoryChip, StatusBadge, PeriodSwitch, BudgetBar, TransactionRow, Icon, CategoryIcon and TabBar are in components/bundle.js as window.Nest.

Components

Button

8px rectangles, never pills. primary is Notion purple, used once per screen for the main action: "Save", "Scan receipt". secondary has an outline for a second choice. dark is near-black for strong utility actions like "Copy last month". ghost is plain text for "Skip" or "Cancel". Labels are a verb in sentence case, at most three words.

Amount

Shows a CAD amount from integer cents with tabular figures. Spending is ink with a true minus sign (−$114.20), income is good green with a plus (+$1,140.00). size="hero" is the one big number at the top of the dashboard. Never colour ordinary spending red.

CategoryChip

A Notion-style pill tab for picking or filtering a category. At rest it is outlined with muted text; when selected it turns solid ink. A small square colour mark shows the category. It's used on the receipt review screen, where tapping a chip moves the selected items to that category, and in transaction filters. Pass the category's slot (1 to 8) as color.

StatusBadge

A Notion tag showing the state of a transaction or budget: Matched (mint), Needs review (peach), Over budget (rose), Draft (grey). Each is a soft tint with deep text and 6px corners. The wording is fixed so each state always reads the same.

PeriodSwitch

A segmented control for Month / Quarter / Year on the dashboard. It takes Apple's layout (one sunken track with the active option raised inside it) and draws it in Notion's style: a warm grey track with 8px corners, 6px segments, and the active segment raised (white, or a lighter grey in dark mode) with a hairline border and 600 weight. Pair it with ‹ › arrows to step between periods. Controlled with value + onChange, or uncontrolled with defaultValue.

BudgetBar

A category budget for the current period, showing what's left in large text and spent of budget in small text. The bar is green below 80%, orange from 80%, and red past 100%; the state is also stated in words ("$32 over"), not only by colour. Stack them inside one card; they divide themselves with hairlines.

TransactionRow

One transaction in a list: merchant, date · account, amount, and a status badge when it isn't routine. A receipt split across categories gets a thin proportional bar and a per-category breakdown, so one Superstore trip reads as Groceries + Baby + Household at a glance. Stack rows inside one card.

Icon

Icons come from Lucide (lucide.dev, ISC licence), the same set shadcn/ui uses. In the app, import them from lucide-react; this page inlines the few it needs.

  • Size and stroke: 20px with a 1.75 stroke by default; 16px in small buttons, 14px with a 2 stroke inside badges, 22px in the tab bar.
  • Colour: icons take currentColor. Plain icons are ink-muted; they turn ink when active.
  • One icon per category. Use the same icon everywhere the category appears: transaction rows, budget lists, the receipt review.
  • Icons sit next to a text label. An icon on its own (like the Add button) needs an aria-label.

CategoryIcon

Each category's Lucide glyph in ink on a soft tint of the category colour (--cat-N at 18%), in an 8px square (36px), or a 6px square (28px) with size="sm". The colour is only in the tint, so the glyph stays readable even for the yellow category. Use the same icon everywhere the category appears: transaction rows, budget lists and the receipt review.

TabBar

The bottom navigation on phones: Home, Transactions, Plan and Settings, with the purple Add square in the middle. Tabs are Lucide icons with a small label, ink-muted at rest and ink with 600 weight on the current page. Add is the one purple control on the bar and opens Scan, Quick add and Import CSV. It leaves room for the iPhone home indicator with safe-area-inset-bottom. On a laptop the same items move to a left sidebar.
